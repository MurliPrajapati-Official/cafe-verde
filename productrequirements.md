# Grill Masters Website PRD

## Project Overview

Build a conversion-focused restaurant website for Grill Masters that transforms online visitors into customers through food discovery, trust-building, reservations, directions, and online ordering.

The website should highlight Grill Masters as an affordable, high-quality fast-food destination in Rohini, Delhi, known for fresh food, Indian-style burgers, wraps, fries, shakes, and a welcoming atmosphere.

The website is not intended to function as a food delivery platform. Delivery and ordering should redirect users to existing ordering channels when applicable.
